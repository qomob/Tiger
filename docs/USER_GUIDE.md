# 使用指南

[返回首页](../README.md)

## 适用对象与工作模式

品牌方可评估营销成果与证据，广告公司可筛选项目、比较赛道和管理准备成本，创意团队可研究作品贡献，技术产品团队可论证真实应用价值。规则查询、赛道研究、证据审查、初步评审、案例写作、视频脚本、金奖答辩可按需调用，不必每次运行完整流程。

## 准备资料

提供经授权的项目方案、执行记录、结案报告、作品、数据原件、统计口径和授权文件。不要上传不必要的个人信息、密码、生产密钥或未获客户许可的材料。尽可能包含真实目标、基线、项目周期、资源投入、核心机制、实际结果及可公开范围。缺失部分保留未知。

## 推荐任务

```text
先筛选：请判断项目的参赛价值，给出最强支持证据与最强反证，
比较适用类别，并只追问最可能改变结论的三个问题。
```

```text
再生产：在不改变事实的前提下，为适配赛道分别组织目标挑战、
洞察策略、实施创新和效果数据；区分内部稿与公开候选稿，附证据ID。
```

```text
最后审查：对候选稿进行模拟评审和数据反证，核对匿名、版权、
公开许可、费用和材料要求。请报告真实程序状态和待人工核验项。
```

## 操作步骤

1. 在宿主按其说明导入整个 Skill 目录，确保 references、workflows 和 scripts 可读取。尚无经过验证的 WorkBuddy 或其他宿主安装教程。
2. 使用 `SKILL.md` 作为入口，先读取已有资料，不重复询问已知信息。
3. 按 [接待与证据](../workflows/intake-evidence.md) 登记项目；按 [赛道选择](../workflows/selection.md) 比较条件及反证。
4. 按 [价值与写作](../workflows/value-and-writing.md) 和 [评审](../workflows/jury.md) 形成初步决策。
5. 有真实独立审查人时，按 [运行指南](../references/runtime-guide.md) 在隔离环境完成签核；没有签核仍可做初评、补证及草稿。
6. 按 [影片与答辩](../workflows/film-defense.md) 和 [交付](../workflows/delivery.md) 制作材料，检查实际文件并人工确认官方字段。未经授权不得上传或正式报名。

## 本地演练

```bash
python3 scripts/roar.py audit examples/v2/project.json --evidence-root examples/v2
```

预期 JSON：`status=REVIEW`，`official_submission=UNVERIFIED_MANUAL_CONFIRMATION_REQUIRED`，`special-18` 的 `fit=UNKNOWN`、`score_range=[0,100]`、`value=INSUFFICIENT_EVIDENCE`，退出码2。样本中的虚构会员运营数据仅用于测试。

`catalog` 查询目录；`fees` 计算假设工本费；`score` 只做算术；`snapshot` 输出签核快照；`audit` 检查 V2 项目。完整字段和命令见运行指南。历史 V1 JSON 仅供回归，不能直接用于 V2 放行。

## 输出与解释

通常包括参赛建议、规则依据、主报/备选/排除赛道、事实登记、反证、未知项、费用情景、补证优先级，以及按需生成的候选稿和物料策划。没有依据不能把模拟分当获奖概率。程序无法运行标记 NOT_RUN；没有 ffprobe 时不声称完成媒体探测。

## 常见问题

- **没有原始数据怎么办？** 先做条件性诊断，要求补充会改变结论的材料；不能自动编造。
- **为什么高分也不能通过？** 加权计算不验证证据或专业评分；规则、适配、签核和交付分开检查。
- **为什么无法直接提交官网？** 本工具不执行报名、支付或网络写操作，官方后台字段仍待核验。
- **能自动审查视频或PPT吗？** 目前仅探测媒体技术属性并检查精确绑定的 UTF-8 文本。视觉、音轨、复杂文档及授权仍需人工审查。
- **新一届规则怎么办？** 先更新并复核对应届次规则；不能套用旧规则宣称已核验。
