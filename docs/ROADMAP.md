# 路线图与发布门槛

当前版本为 v2.0.0-rc.1，内部试用候选，生产 NO-GO。以下为计划而非承诺的完成日期或已实现能力。

| 阶段 | 当前裁决 | 后续重点 |
| --- | --- | --- |
| M0 工程基线 | PASS | 保持历史回归 |
| M1 证据治理 | PASS-BOUNDED | 语义冲突、真实来源与信任根隔离 |
| M2 专业赛道 | PARTIAL | 官方原文复核、真实准确率 |
| M3 案例研究 | PARTIAL | 合法取得完整案例与负向样本 |
| M4 专业评分 | PASS-BOUNDED | 独立专业判断与消融实验 |
| M5 生产验收 | PARTIAL | 同模型四组盲测、真实业务与宿主验证 |

真实验证计划为60个任务，四组相同模型及工具条件比较；必须保存原始输出、专业标签、成本及失败案例。不得把历史获奖直接当质量标签。拟议目标包括赛道准确率≥90%、低质量识别率≥85%、优质案例误否决率≤10%、关键事实引用≥98%、相对裸模型专业度提升≥15%。这些不是已取得成绩。

发布前核验当前官方规则与实际报名字段；检查实际宿主安装、工具权限、签核隔离和降级路径；完成真实独立盲评；权利人审核公开材料及许可证；基于结果定点整改并冻结版本。详情见 [验证协议](../evaluation/PROTOCOL.md) 和 [验收报告](../ACCEPTANCE.md)。
