# 交付验收
输出项目档案、规则版本/来源、资格报告、赛道比较与预算、事实登记簿、补证清单、分赛道内部稿、可公开稿候选、视频脚本、模拟评审与修订记录、物料清单、确认函及授权检查、人工批准单。内部稿不得直接作为外部稿；每条外部事实由人复核，删除保密数据及身份标识，检查图文/视频/音轨/附件元数据。按手册p9提报系统下载实际模板与盖章确认函，核对实际字段/长度/嵌入平台、审查通知及不可撤回条件。未访问后台不可输出READY；历史V1 CLI INTERNAL_CHECKS_PASSED 仅表示实现范围内结构通过，不能替代人工、官方确认。

批量项目：按主体、真实作品ID、赛道、负责人、截止、合规、证据状态及预算列台账；原则20作品（手册p1），超出人工确认。未经用户明确授权，不向官网或第三方上传、创建账户、提交、支付或发送文件。本 Skill 不实现网络写操作。

## V2最终门禁
每个类别最终绑定文本的UTF-8字节须与drafts逐行一致，包括结尾换行；登记实际相对路径/hash，不允许未审行混入。它是可核验事实清单/候选事实稿，不能自动认证完整创作叙事；可编辑稿、脚本、图片和视频单独审查。实际媒体与声明逐项对齐，核对hash、大小，ffprobe可用时探测格式/流/时长，不能替代内容、版权、匿名审查。项目签核后更改任何字段或文件需重新验签与核验。不得称READY。
