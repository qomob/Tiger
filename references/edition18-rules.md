# 第18届虎啸奖规则基线
来源：用户上传《第18届虎啸奖（2026-2027）参赛手册》，43页。下述页码为印刷页，关键规则同时标注PDF页；前部P01–04的PDF页为6–9，P05–06组织表为PDF10，之后为印刷页+4。规则为本届快照，官网更新须另核实。

## 赛事与日期（印刷P01–03，PDF 6–8）
主题：角色重塑·价值升维；主办虎啸奖组委会，承办虎啸文化。报名 2026-11-28 至 2027-03-19；线上评审 2027-03-26 至 04-02；04-09左右开放入围查询，线下终审 04-09 至 04-10；金奖答辩 04-22 至 04-23；盛典 06-03 至 06-05。作品创意、制作、投放/实施窗口为 2026-03-20 至 2027-03-19（P08、P15，PDF 12、19）。不要把作品窗口与报名期混同。原则上每家行业公司提报案例作品不超过20个；另备公司logo用于获奖后对外宣发，与匿名评审材料分离。报名入口 https://case.hooxiao.com/ ，国际入口 https://encase.hooxiao.com/ ，官网 https://www.hooxiao.com/ 。历史案例库见虎啸文化小程序、提报系统参考案例。当前访问超时，控制台模板需用户登录后提供；不声称已全面抓取官网。

## 资格与费用（P08–11，PDF12–15）
商业主体注册：品牌主、代理公司、媒体平台、技术公司及相关企业机构。每年需重新注册。共同创作须合作方授权且确认函双方盖章；提交者对版权争议负责。禁止非原创/抄袭、版权不能证明、违法违规及严重不良商业行为；超作品时间窗口、匿名违规、上一年度弃奖/选奖等不遵守评审规则者存在取消资格情形。不得露参赛公司及合作方身份（公司名、logo、水印等；广告主、媒体平台例外，具体判断参见类别条款）。不接受选奖、弃奖，组委会保留通报评审团及禁赛三年权利。获奖后的注册、案例及正文信息不可修改；提交成功后不可撤回。不可公开信息在提交前删除；提交即授予组委会宣传、使用及出版权，获奖作品将进入小程序等展示。需确认真实授权、保密条款及可公开数据范围。
免费参赛；案例获奖才按获奖作品数量收工本费。全场大奖/评审团大奖 8600元/个；营销案例、创意作品、电商类金银铜 8600元/个（奖杯+证书），优秀奖3800元/个（证书）；技术产品年度最佳系统/工具/平台 8600元/个；机构人物中的品牌奖8600元/个，品牌人物0；行业机构、人物奖0；加订奖杯3800元/个、证书360元/个。多类别会生成多个作品，最终按获奖作品数收费；预算情景不预估获奖概率。行业公司/人物/团队为提名制。费用以官方当前确认及实际奖项为准。

## 提报流程（P09–10，PDF13–14）
注册、登录、下载确认函并盖章上传扫描件（必需）、查参考案例及素材包、选类别并填报、待审核→等待修改或审核通过；审核通过代表报名成功，不等于获奖。线上初审后查入围，全部评审结束后秘书处邮件通知。使用电脑浏览器，手册提示提报系统不适用微信手机/电脑客户端。以实际模板为准；繁体转简体；图片须插入而非复制粘贴，JPG、原则上每案例不超过12张，禁止参赛公司标识水印。视频/音频/在线视频合计限5个以内；本地视频MP4、本地音频MP3，大小100M以内（以控制台对具体文件计量为准）；在线视频使用指定平台分享嵌入代码。视频强关联类别必须提交视频，音频强关联类别须提交音频，否则影响分数；图片建议上传。不是所有类别强制Case Film。

## 类别数量与评审（P13–30，PDF17–34）
综合类按广告主行业，单项按营销手段；同一营销案例最多1个综合+2个单项，平级无需绑定（P15 PDF19）。创意作品同一案例最多2个创意作品子类别（P21 PDF25）；电商最多2个子类别（P22 PDF26）；技术产品同一产品最多1个（P23 PDF27）。第1、2、3案例大类可跨大类提报（P13 PDF17），不可把跨大类理解为不限数量。品牌形象、品牌产品、品牌人物的主体要求及每组最多1个类别见P24 PDF28；行业公司/人物/团队无需主动提报，组委会依据案例提报及获奖情况提名（P27–28 PDF31–32）。跨类具体合并边界如控制台不同，向组委会核实。
线上初审→线下终审；营销案例/电商金奖提名案例进入答辩，创意作品/技术产品不参加金奖答辩；机构人物评审走相应品牌/行业路径（P29 PDF33）。手册示意初审约28%进入终审，金奖提名1–2%、银5–6%、铜9–10%、优秀10–12%，可按类别提报情况调整（P10、P29–30 PDF14、33–34）。这些为赛事流程比例，不是个案概率。金奖答辩仅受通知者参加，最终由评委投票决定；详见通知与P29，手册P29明确每案例10分钟，其中陈述7分钟（含案例视频），评委提问3分钟；到时停止。金奖答辩现场PPT陈述并问答，投票半数以上确定最终金奖。全场大奖、评审团大奖从金奖案例评出，可空缺。行业公司人物及团队并非按普通案例四维打分。
